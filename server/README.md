# Kudos Kit API

The NestJS API of Kudos Kit: feedback intake (`POST /v1/feedback`), the dashboard API, sign-in
(Better Auth) and emails. It also serves the widget script at `/kkw.js`.

Setup, local development and deployment are explained in the main [README](../README.md) and
[DEPLOY.md](../DEPLOY.md). Local settings: copy `.env.example` to `.env`.
